In a collaboration with University Hospital Frankfurt I apply **statistical methods and machine learning to clinical data**. As part of the Volkswagen Foundation–funded project *"From Machine Learning to Machine Teaching,"* this work aims to better understand diseases such as post-COVID conditions and community-acquired pneumonia.
